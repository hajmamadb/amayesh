## ساخت دوباره‌ی فایل Word

```
node "D:\amayesh\سند آمایش\01_طرح_توسعه_یافته\build\build_docx.js"
```

- کتابخانه‌ی `docx` از مسیر `D:\آمایش2 زد\01_طرح_توسعه_یافته\build\node_modules\docx` (نسخه ۸.۵.۰) با require مستقیم CJS لود می‌شود.
- ورودی: همه‌ی `md\*.md` به ترتیب نام فایل؛ خروجی: `سند_آمایش_استانی_طرح_توسعه_یافته.docx`
- فرمت: A4، فاصله ۲ سانتی‌متر، فونت B Nazanin، بدنه ۱۲pt با فاصله‌ی خط ۱٫۵، JST/RTL، جدول‌های سرتیتر آبی، بلوک‌های SQL با فونت Consolas و پس‌زمینه‌ی خاکستری، شماره صفحه در پابرگ.

## درباره‌ی طول سند

- ۲۰ فایل فصلی ≈ ۲۰۸٬۰۰۰ نویسه‌ی فارسی (بدنه + ≈۴۲۰ ردیف جدول شاخص + بلوک‌های SQL + پیوست‌ها).
- در تنظیمات فرمت مذکور (۱۲pt، ۱٫۵ خطی، A4) خروجی Word تقریباً **۱۰۰ تا ۱۱۰ صفحه** است.
